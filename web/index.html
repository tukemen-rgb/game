解析の六段階
01

入れ物を開ける

ISO9660 のボリューム記述子からディレクトリを辿り、ファイル一覧を取り出す。

02

性質を地図にする

ブロックごとのバイト統計で六種に色分けする。ゼロ埋め・ASCII・日本語・タイル・波形・圧縮。

03

構造を推定する

文字列の並び、ポインタテーブル、タイルの周期を自動で探し、根拠つきで確度を出す。

04

手で確かめる

16 進表示、文字列一覧、タイル表示、相対検索。推定を人が検証する。

05

分かったら読む

形式が判明したファイルは本文まで展開する。ここを増やすことでツールが実用になる。

06

コードを読む

本体プログラム (ELF32 / MIPS R5900) を命令に戻す。どの文字列をどこで使っているかまで辿る。

できないこと

      位置長さ形式内容
      
            
          
      
        
      
      
      

      
      
      
        
      
          値が単調に増え、すべてファイル内を指している並びを探します。基準の値は決め打ちにせず、複数の仮説を立てて根拠の多いものを採ります (イメージの中に埋まったファイルのポインタも拾えます)。根拠は二つ —

          読み方のとっかかり
          
      
            
      MIPS には 32 ビットの値を 1 命令で作る方法がありません。だから住所はいつも lui (上位 16 ビット) と addiu / ori (下位 16 ビット) の 2 命令に割れます。この組を追いかけて復元したアドレスを → の後ろに出しています。そこに文字列があれば中身も並べます。どの文字列をどこで使っているかが、これで分かります。
      
            
      分岐や呼び出しの行き先はクリックで飛べます。jal が関数呼び出し、jr $ra が関数の終わり。jr $ra の次の 1 命令は遅延スロットといって、戻る前に必ず実行されます (MIPS の癖です)。
      
            
      引数は $a0〜$a3、戻り値は $v0。関数の頭で addiu $sp, $sp, -N と sw $ra, ... が出たら、そこが関数の入口です。
      
          
      
        
      
      
      

      
      
      
        
      ここまでに分かったことを、そのまま人に見せられる形にまとめます。解析はこの画面の中だけで完結していて、データはどこにも送られません。だから相談したいときは、この文章を自分でコピーして渡す必要があります。中身は位置・分類・根拠だけで、ファイルそのものは含みません。
      
        
      
          
          
          
        
      
        
      
      

      
      
      
        
      バイトの性質が「タイル・コードなど」で、かつある間隔だけ離れたバイトが隣のバイトより似ている領域を探しています。画像は縦に相関があるので、その間隔が 1 行の長さになります。圧縮データや波形はこの条件で落ちます。

          会話テキストを読む (.msg / 僕の夏休み 2)
          
      この作品のテキストは圧縮ではなく、フォント画像の並び順をそのまま文字コードにした 2 バイトの並びでした (英語化パッチの公開ソースで確認)。だから Shift-JIS で検索しても出てきません。ファイルは「件数 + 位置表 + 本文」の形で、本文の 0x8000 が終わり、0x8001 が改行、0x8002 が待ち時間です。.msg を選んでから押してください。
      
          
      
            
            
            
          
      
          
      物語の会話は MAP フォルダの各ファイルにあります。それは「項目数 + 位置と長さの表」の入れ物で、切り分けた 1.bin に表が複数入った会話ファイルが入っています (公開ソースで確認)。メニュー類は BOKU2.IMG 内の .msg です。
      
          
      
            
            
          
      
          
      
        
      

        
      
          圧縮を解く (LZSS)
          
      圧縮されたデータ一般のための道具です。日本のゲームで最も多い LZSS (奥村版) で伸張を試します。当たれば読め、外れれば独自変種です。(僕の夏休み 2 のテキストは圧縮ではないと分かったので、この作品では上の .msg 読みを使ってください。)
