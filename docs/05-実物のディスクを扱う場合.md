# 実物のディスクを扱う場合

このリポジトリの練習には実物のソフトは必要ありません。それでも
「実機のデータはどう手に入れるのか」を知っておくと全体像が繋がるので、
技術的な流れと、その前に確認すべきことを整理しておきます。

## 技術的な流れ

PS2 のディスクは標準の DVD-ROM / CD-ROM です。**専用の読み取り機は不要で、
普通の PC 用 DVD ドライブ (内蔵・USB 外付けどちらでも) で読めます。**

1. **イメージ化** — ImgBurn の Read モードなどでディスク全体を `.iso` にする。
   以降は原本に触らず複製データだけで作業する
2. **中身を見る** — 7-Zip で展開するか、Windows 標準の機能で `.iso` をマウントする
3. **ファイルを絞る** — テキストが入っていそうなファイルを探す。
   `.BIN` `.DAT` `.PAK` `.AFS` のような拡張子や、サイズの大きいアーカイブが候補
4. **文字コードを見る** — バイナリエディタ (HxD) で開き、Shift-JIS の日本語が
   そのまま見えるか確認する → [01-文字テーブル.md](01-文字テーブル.md)
5. **独自コードなら相対検索** — Monkey-Moore で位置とテーブルを割る
   → [02-相対検索.md](02-相対検索.md)
6. **フォントが画像なら** — Crystal Tile 2 でグリフの並びから文字テーブルを作る
7. **画面と照合する** — PCSX2 (PS2 エミュレータ) で `.iso` を起動し、
   「画面のセリフ」と「データ上の文字列」を突き合わせる

7 番が一番効率的な学び方です。データ上のどのバイト列が画面のどのセリフに
なるのかを目で確認できるので、推測が確信に変わります。

なお 3 番の「ファイルを絞る」が実は一番手間のかかる工程です。ひとつの
巨大なアーカイブに全部詰まっていて、その中身の構造から解析しないと
テキストに到達できないことも珍しくありません。このリポジトリの
`work/SCRIPT.BIN` のように素直に置いてあるのは、練習用だからです。

## 安全面

**技術面** — 上に挙げたツールはどれも定番で、正しく使えば PC もディスクも
壊しません。読み取りは読み取り専用の操作です。ただしソフトは公式・信頼できる
配布元から入手してください。ツール名で検索すると偽の配布サイトが上位に
出てくることがあります。

**法律面** — ここは技術の話とは別に、はっきり認識しておく必要があります。

* 日本の著作権法では、自分が持っているソフトであっても
  **コピーガード (技術的保護手段) を回避したコピーは、私的目的でも違法に
  なり得ます。** PS2 ソフトはこれに該当する場合があります。
* 取り出したデータの配布、改変したものの公開は、明確に問題になります。
* 最終的な法的判断は、この文書ではなく専門家に確認してください。

つまり「技術的にできる」と「やってよい」は別問題です。

## 権利面がクリアな題材で同じ練習をする

重要なのは、**ローカライズ・校正の技術そのものは、権利的に問題のない題材で
まったく同じように練習できる** ということです。このリポジトリがその一例です。

ほかの選択肢:

| 題材 | 良い点 | 注意点 |
| --- | --- | --- |
| このリポジトリの疑似データ | 答えがある。構造を自分で変えられる | 実データ特有の癖はない |
| 自作のテストデータ | 好きな構造を試せる | 自分で作る手間 |
| フリーの同人ゲーム | 実データの手触りがある | 改変・再配布の許諾条件を必ず確認する |
| オープンソースのゲーム | 権利関係が明確 | テキストが素のままで解析の練習にならないことも |
| 練習用に公開されている ROM ハック素材 | 教材として整備されている | 素材自体の出所を確認する |

## 実務ではどうなるか

将来ローカライズ QA・校正の仕事を目指す場合、**吸い出しの技術を使う場面は
ほぼありません。** 開発元から正規のテキストデータ (Excel、XLIFF、専用ツール
上のデータなど) を受け取るのが普通です。

代わりに毎日効くのは、このリポジトリで扱っている中身の理解です。

* 文字コードとフォントの仕組み → 文字化け・□ の切り分けができる
* 表示幅と行数の制約 → 訳文を作る時点で入る形にできる
* ポインタと容量の制約 → 「入りません」と言われる理由が分かる
* 変数と制御コード → 壊してはいけないものが分かる

だから練習の重点は「吸い出せるようになること」ではなく
「取り出したあとに何を見るか」に置くのが正解です。
